# Secure Password Manager

## Overview

This **Secure Password Manager** provides a robust solution for storing and managing your passwords securely. The application includes user registration, login, password encryption, and OTP-based two-factor authentication (2FA) to ensure your credentials are protected at all times. 

It leverages modern cryptographic techniques like AES and PBKDF2 to securely hash passwords and encrypt sensitive data. Additionally, the system integrates MongoDB for secure storage of user data and passwords. 

## Features

- **User Registration & Login**: Secure registration and login process using PBKDF2 for password hashing and AES for encryption.
- **Password Storage**: Store and retrieve website credentials (username and password) securely, encrypted with AES.
- **OTP Authentication**: Time-based One-Time Password (TOTP) for additional security.
- **Password Expiry Check**: Automatically checks if a password has expired (30 days).
- **Password Strength Checker**: Ensures passwords meet strong security criteria, checking against common passwords and enforcing character diversity.

## Cryptography Techniques & Security Algorithms

### AES (Advanced Encryption Standard)
AES is the cornerstone of our encryption system, used for securely encrypting passwords and sensitive data.

#### Key Operations:
- **S-Box (Substitution Box)**: Non-linearly substitutes bytes to secure encryption.
- **Inverse S-Box**: Used for reversing the substitution during decryption.
- **Rcon (Round Constants)**: Used to generate round keys, ensuring robust security.

#### AES Functions:
- `encrypt_block()`: Encrypts a 16-byte block using AES-256.
- `decrypt_block()`: Decrypts a 16-byte block.
- `encrypt_cbc()`: Encrypts plaintext using AES in CBC mode with padding.
- `decrypt_cbc()`: Decrypts CBC ciphertext and removes padding.

### PBKDF2 (Password-Based Key Derivation Function 2)
PBKDF2 is used for securely hashing passwords, making it resistant to brute-force attacks.

- **Inputs**: User password, salt, iterations, and key length.
- **Hashing Process**: Iterates multiple times to slow down the key derivation process, increasing security.

### TOTP (Time-based One-Time Password)
TOTP provides an additional layer of security by requiring a time-sensitive OTP for login.

- **Shared Secret Key**: A random key shared between the server and user, stored securely.
- **OTP Generation**: OTP is generated based on the current time and hashed with the shared secret.
- **OTP Verification**: Verifies user-entered OTP against the server's generated OTP.

### Password Expiry
The system checks if a user's password is expired by comparing the last update date with the current date. If the password was last updated more than 30 days ago, it is considered expired.

## How It Works

1. **User Registration**: Users create an account by providing a username and password. The password is securely hashed using PBKDF2, and the OTP secret is encrypted using AES.
2. **Password Management**: Users can store website credentials (username and password) securely. Each credential is encrypted using AES before being stored in MongoDB.
3. **Login Process**: During login, the password entered is hashed and compared to the stored hash. The user must also provide the correct OTP generated by their authenticator app.
4. **Password Expiry**: The system ensures passwords are updated regularly by checking their last update date.
5. **Password Strength**: The password strength checker enforces strong password requirements before registration or password change.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/password-manager.git
    cd password-manager
    ```

2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. Set up MongoDB:
    - Ensure MongoDB is running on `localhost:27017`.
    - Create a database named `password_manager` and a collection named `users`.

4. Run the application:
    ```bash
    python app.py
    ```

## Security Considerations

- **AES Encryption**: The system uses AES-256 encryption in CBC mode, ensuring strong data encryption.
- **Password Hashing**: Passwords are hashed using PBKDF2 with a high number of iterations (500,000), making brute-force attacks computationally expensive.
- **TOTP**: Adds an extra layer of security by requiring a time-based OTP for login, preventing unauthorized access.
